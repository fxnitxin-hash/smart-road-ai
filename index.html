Connect AI pothole model

Model requirement: Automated detection needs a trained pothole object-detection model hosted by an inference service. This app supports the Roboflow hosted inference API pattern. A model ID and private API key are required. Do not publish your API key in a public app.

For a public or production deployment, put inference behind your own backend so the API key is not exposed in the browser. Browser inference may also be blocked by provider CORS or account settings.

How the severity estimate works

The prototype estimates severity from the detected bounding-box area relative to the image. This is only a rough visual proxy, not pothole depth, engineering assessment or a road-safety certification. Verify reports manually before maintenance decisions.

Low: smaller detected area · Medium: moderate area · High: larger area. The user can override the category before submitting.
